## 📖 Description
**Nice Mob Manager** is a super versatile tool that lets you control pretty much everything about mobs. It uses Mojang’s new Dialog system to give you easy, menu-based access to tons of features — only one command needed. You can tweak individual mobs or mob groups, add cool stuff like rarities with better loot, randomize gear, and even mess with vanilla gamerules. If you’ve thought about it, chances are you can do it.


<details>
<summary>Command to open the Menu</summary>

```
/function mob_manager
```

</details>



## 📋 Features

### Mob Settings
Tweak stuff like size, attack damage, health, and head drop chances for individual mobs or groups — perfect for dialing in your ideal playstyle or server vibe.

### Rarity Mobs
Set up special mobs with rarity tags. They’re tougher by default and drop better loot — because rare should feel rare.

### Mob Equipment
Randomize what gear mobs can spawn with — from helmets to boots. Mix it up or go full chaos mode.

### Additional Mob Drops
Add extra drop chances for certain mobs — like letting Husks drop Sand or giving the Ender Dragon a shot at dropping a Dragon Egg.

### Vanilla Gamerules
Easily check and tweak mob-related vanilla gamerules without digging through commands.

### Villager Settings
Give Villagers custom names, randomize baby types, and even let them name their meeting points (or keep it boring, up to you).

### Wandering Trader Settings
Control announcements, glowing effects, and set up fun trades like Miniblocks, Plushies, or Enchanted Books.

### And many more!
There’s a ton more to explore — you’ll just have to dive in and see what you can mess with.

## 🛠️ Technical Gibberish
This data pack double functions as the **optional** resource pack needed for the Spawn Egg Locator Bar Icons. So simply slap that one also into your Resource folder and make sure to enable it in game for the textures to show properly. _(This is not needed for the auto converted mod versions)_

Custom Dialogs/Menus were first introduced in Minecraft 1.21.6 - Therefore a backport to older versions is simply not possible!

For **PaperMC users**, it is recommended to set the `paper.maxChatCommandInputSize` property to a value between 512 and 1024. More information can be found in the [PaperMC Docs](https://docs.papermc.io/paper/reference/system-properties/#papermaxchatcommandinputsize). Also make sure to have `allow-non-player-entities-on-scoreboards` enabled in your paper configs.
